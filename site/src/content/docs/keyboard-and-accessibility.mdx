You can use all of Huddle with a keyboard, and it is built to work with screen readers. This page lists the shortcuts and explains how keyboard navigation works.

## Shortcuts

| Key | Where | What it does |
| --- | --- | --- |
| Ctrl+K (Cmd+K on a Mac) | Anywhere | Open search |
| Enter | Message box | Send |
| Shift+Enter | Message box | New line |
| Up | Empty message box | Edit your last message |
| @ | Message box | Mention someone |
| Up, Down, Enter, Tab, Esc | Mention list | Choose, pick or close |
| Ctrl+B / Ctrl+I | Message box | Bold / italic |
| Enter / Esc | Editing a message | Save / cancel |

## Moving through messages

A long history doesn't stand between you and the message box. The whole list of messages is a single stop when you press **Tab**:

1. Press **Shift+Tab** from the message box to reach the newest message (or the one you were last on).
2. Use **Up** and **Down** (or **Page Up** and **Page Down**) to move one message at a time, and **Home** and **End** to jump to the oldest and newest loaded message.
3. Press **Tab** on a message to reach its own buttons: **Add reaction**, **Reply in thread**, **Edit** and **Delete**.
4. Press **Esc** to go back to the message box.

The first thing **Tab** reaches on the page is **Skip to conversation**, which jumps past the sidebar.

## Screen readers

- New messages that arrive while you're in a conversation are announced.
- Each message is labelled with its author and time.
- Reactions say which emoji, how many and who reacted, and whether selecting it adds or removes yours.
- Errors and "Saved" notes are announced when they appear.
- Typing indicators are announced politely, without interrupting.

## Motion and contrast

Huddle follows your system's **reduce motion** setting. Text meets WCAG AA contrast, and when admins pick a [brand colour](/docs/branding), Huddle refuses colours that would make buttons hard to read.

## How it's checked

Every screen and dialog is tested automatically against WCAG 2.2 A and AA, and keyboard flow and screen-reader wording are tested separately. If you find something that doesn't work for you, please [open an issue](https://github.com/Pieter1821/Huddle-Team-Chat/issues).
