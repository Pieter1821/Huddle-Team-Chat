You can share files in any conversation you can post in. This page covers how to attach them, what the limits are and who can see them.

## Attach files

Any of these works:

- Select **Attach files** (the paper clip) next to the message box.
- Drag files onto the message box.
- Paste an image or file into the message box.

Each file starts uploading as soon as you add it and shows its progress. You can add a message or send the files on their own, and select **Remove** on a file to take it off before sending. If you press **Enter** while files are still uploading, Huddle tells you to send again when they're ready.

## Limits

- Up to **25 MB** per file.
- Up to **10 files** per message.
- Files you upload but never send are removed after a day.

## How files appear

- **Images** (PNG, JPEG, GIF and WebP) show in the conversation. Select one to open it full size.
- **Everything else**, including PDFs, Office documents, zips and text files, appears as a card with its name and size. Select it to download.

Huddle checks what each file really is, not just its name. A program renamed to look like a photo is still only offered as a download, and never opened in the browser.

## Who can open a file

A file belongs to the conversation it was shared in. Only people who can read that conversation can open it, and every download is checked. If the message is deleted, its files can no longer be opened.

Files are kept in your own private storage on Cloudflare. None of them has a public link, so nobody outside your workspace can open them.

## Find files later

[Search](/docs/search) also looks at file names, so typing part of a name finds the file and the message it was shared in.
